# EXIS Žilina

Responzívny prezentačný web spoločnosti EXIS Žilina s novou vizuálnou identitou.

## Obsah
- `index.html` – obsah a štruktúra stránky
- `style.css` – vizuálny štýl a mobilné rozloženie
- `app.js` – mobilná navigácia a aktuálny rok v pätičke
- `assets/` – logá, značka a favicon

## Spustenie
Stránka je statická. Stačí otvoriť `index.html` v prehliadači alebo súbory nasadiť na statický webhosting. Externé fonty sa načítavajú z Google Fonts.
